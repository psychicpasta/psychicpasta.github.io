## Category One : Software Design and Engineering
### Artifact : 3D Replica Scene - CS 330 Computer Graphics and Visualization
### [Original Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category1OriginalArtifact)
### [Enhanced Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category1EnhancedArtifact)

The artifact that I have selected for this category is a 3D scene that I developed in 07/2025 for the CS 330 course at SNHU. The purpose of the project was to capture a scene of objects in real life, and attempt to recreate that same scene in a digital, 3D environment. This consisted of generating and placing the shapes in a way to properly represent the real life objects, and apply color, texture, and lighting to the scene to make it as realistic as possible.

I selected this artifact to be included in my ePortfolio because I think it is a unique project that allows me to showcase a fine tuned set of skills. Being able to create 3D art shows a level of mathematical skills that are needed to understand the geometry of the real world. It also promotes my ability to program in C++, a highly respected and desired programming language in the job market. With my enhancement, the user can now turn off (‘N’ key) and turn on (‘M’ key) the lights of the scene at the click of a button on their keyboard. This gives the user more control over the scene, along with the camera movement and projection view changes. I think that this enhancement promotes my abilities on both a design and technical level. On a technical level, it shows that I can connect external input from a device to a program to have major control, which would be useful in a game or other 3D development project. On a design level, it shows that I have a user-focused mindset, and consider giving them more features to interact with as an enhancement to the overall project.

With these enhancements, I believe that I have met the course outcomes I was striving to meet in Module One. I think the enhanced 3D scene is a technically sound visual communication that accurately represents the real world scene it was intended to replicate. I also was able to put my innovative skills and computing technique to good work to further develop the 3D scene and deliver an industry standard product.

When I was working on the enhancements, I was immediately reminded how much I enjoyed developing the original artifact in my CS 330 class. It was a fun experience because it was a type of project I have never worked on before, and it was interesting to learn how 3D scenes are developed. As I was working on the enhancement, I actually realized that the original lighting in the artifact could use a touch up. So before I continued adding the M and N button functionality for turning the lights on and off, I tweaked the positioning and strength of the lighting to make it more visually appealing. This was a learning moment for me that code can always be improved and enhanced, no matter what level you think it is currently at. Which was a challenge for me as well because I kept thinking of new ideas to enhance it outside of my proposal. I may even continue working on it after this course is complete.

## Category Two : Algorithms and Data Structures
### Artifact : Rescue Animal Reserve System - IT 145 Foundation in Application Development
### [Original Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category2OriginalArtifact/it145_54)
### [Enhanced Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category2EnhancedArtifact/it145_54)

For the Category Two enhancement, I have chosen the Rescue Animal System I created for the IT 145 course here at SNHU. It acts as a tracking system for animals within a Rescue Animal program. The program is intended to be used by a company or group that takes in rescue animals and trains them. It monitors specific attributes of the animal such as its name, gender, weight, training status, etc. The original artifact allows you to intake either new monkeys or dogs and add them to the running list, print a list of all the dogs, or print a list of all of the available animals in the system.

I selected this item because it was one of the first projects I worked on in the Computer Science program at SNHU. I knew that there would be a lot of room for enhancement, and that I could make improvements with all of the knowledge I now have at the end of the program. In order to improve this artifact, I added more functionality to the program. After the enhancement, the user can now update an existing animal or remove it from the system entirely. This is a great showcase for my data structures skills because I had to properly manipulate the data within the code using the available functions of an ArrayList in order to allow the user to be able to manipulate the data from a user interface. Since there are two different animal types with different attributes, I had to be wise about how I implemented the methods in order to use space and time in the most efficient way possible.

With these enhancements, I believe that I have met the course outcomes that I planned on meeting. I think this artifact now supports a collaborative environment so that the rescue animal group can now more accurately and effectively track the animals in their system. I also designed a computing solution that used an algorithm to properly edit or remove the requested type of animal. To avoid having repeat code running, I did my best to have separate methods when possible for the two different types of animals.

As I mentioned, this was one of the first projects I worked on at SNHU. I enjoyed going back and seeing the code I had written a year ago. I think that I have learned a lot and as I was adding my enhancements, I even saw room for improvement in the areas of the artifact that were not planned to be improved. In that same thought, a challenge was having to work with some of the choices I made when I had less computer science knowledge. A less efficient choice made before influenced the enhancements I was making for this category.

## Category Three : Databases
### Artifact : Rescue Animal Reserve System - IT 145 Foundation in Application Development
### [Original Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category3Original_Artifact/it145_54)
### [Enhanced Artifact](https://github.com/psychicpasta/psychicpasta.github.io/tree/main/Category3Enhanced_Artifact)

For the Category Three enhancement, I have chosen the Rescue Animal System I created for the IT 145 course here at SNHU. It acts as a tracking system for animals within a Rescue Animal program. The program is intended to be used by a company or group that takes in rescue animals and trains them. It monitors specific attributes of the animal such as its name, gender, weight, training status, etc. The original artifact allows you to intake either new monkeys or dogs and add them to the running list, print a list of all the dogs, print a list of all of the available animals in the system, update an existing animal in the system, or remove an animal from the system.

I chose this artifact because it was one of the first projects I worked on at SNHU, so I thought it would be interesting to see how I can enhance it with the skills I learned throughout my courses. Before the enhancement, the data created and updated during the program’s runtime would not be saved in between compilations. I thought the perfect enhancement for this category would be to add persistent data to this system. Any data created or changed will carry over if you run it again using functions that save and load the data for the Array Lists from a json file. There is also now a level of security because it asks for a username and password to access the system when you first run it which protects the data.

I did meet the course outcomes I planned to. With the security updates, it proves that I have a security focused mindset, and am always thinking of ways to protect the data for the customer.

When it came time to implement the security aspect, I thought back to my CS 305 course. There was an assignment where you had to write a hash function to encrypt a password and password input so it was not stored in the code in plain text. I used the same SHA-256 hash encryption and was able to reuse that function. I learned how important it is to keep old projects because you never know when it will come in hand for another.
